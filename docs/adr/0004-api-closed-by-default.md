# Close the API by default

Every route under `/api` requires the User's session except the exact paths `/api/auth/status`, `/api/auth/setup`, and `/api/auth/session`; `/health/*` stays open for platform probes. Mounting a route under `/api/auth` does not make it public: each exception must be added to the allowlist deliberately. New routes are therefore private unless explicitly exempted, rather than private only when someone remembers to guard them; `/api/meta` moved behind the session for the same reason, which costs an unauthenticated caller the version string and costs the smoke tests one claim. This is what makes "before setup, only setup and health are reachable" a property of the router instead of a rule each future ticket has to re-apply.
