# Close the API by default

Every route under `/api` requires the Owner's session except `/api/auth/*`, and `/health/*` stays open for platform probes. New routes are therefore private unless they are deliberately mounted under `/api/auth`, rather than private only when someone remembers to guard them; `/api/meta` moved behind the session for the same reason, which costs an unauthenticated caller the version string and costs the smoke tests one claim. This is what makes "before setup, only setup and health are reachable" a property of the router instead of a rule each future ticket has to re-apply.
