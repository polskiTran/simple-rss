## v1
Explicitly excluded from v1:

- Read/unread state
- Multiple users
- Native mobile applications or PWA behavior
- Offline synchronization
- Feed autodiscovery
- Tags, folders, ranking, and notifications
- Persisted article HTML or Markdown
- Multiple replicas or high availability
- Automatic application updates


## v2
- Feed autodiscovery
- Tags or folders
- Configurable retention
- Optional off-platform backups
- Additional deployment guides
